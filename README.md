# Team_Fource
money saving app
PRODUCT PLAN
Smart Saving Habit
スマート貯金習慣アプリ
コンセプト
お金の流れを「見える化」して、楽しく続く貯金習慣をサポート！
概要
収入を入力し、カテゴリごとに予算を設定。毎日の支出を簡単に記録することで、お金の流れを見える化し、無理なく貯金を続けられるアプリ。
現状分析
・無駄遣いが多い
・お金の使い道を意識していない
・目標がなく、やる気が続かない
 
市場の課題
・家計簿アプリは入力が面倒で続かない
・モチベーションを維持できる仕組みが少ない
・節約アドバイスがパーソナライズされていない
それによって起こる問題
・無駄遣いが増え、貯金ができない
・収支バランスが崩れ、金銭的ストレスが増える
・目標がないため、継続的な貯金習慣が身につかない
解決策
・お金の流れを見える化し、使いすぎに気づけるようにする
・簡単に記録できる仕組みで継続をサポート
・目標設定やストリーク機能でモチベーションを維持
・AI分析で節約アドバイスを提供
主な機能
・収入入力
・支出カテゴリ管理
・支出記録
・デイリーストリーク
・貯金目標管理
・グラフ・分析
・AI支出分析
・バッジ・達成システム
ターゲット
・学生
・留学生
・若い社会人
・貯金習慣を身につけたい人
他のアプリとの差別化
・シンプルで使いやすいインターフェース
・ストリーク・バッジ機能で楽しく継続
・AI分析によるパーソナライズアドバイス
・目標管理でモチベーション向上
期待される効果
・支出管理の意識向上
・無駄遣いの削減
・継続的な貯金習慣
・モチベーション維持
使用技術
Frontend: React Native (Expo)
Backend: Supabase (PostgreSQL)
Language: TypeScript
Libraries: Chart.js / Zustand
